# Материалы группы — блог без бэкенда

Статический сайт: `index.html` + `posts.json`. Публикация постов идёт прямо из браузера через GitHub API, отдельный сервер не нужен.

## 1. Разместить на GitHub Pages

1. Создай новый **публичный** репозиторий, например `group-blog`.
2. Залей туда файлы: `index.html`, `style.css`, `app.js`, `posts.json`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root`.
4. Через минуту сайт будет доступен на `https://<твой-юзернейм>.github.io/group-blog/`.

Ссылка на конкретный пост выглядит так:
`https://<юзернейм>.github.io/group-blog/#/000002`
(`#` нужен, потому что GitHub Pages не умеет отдавать "красивые" пути без сборки сайта — если очень нужно без `#`, скажи, добавлю 404-редирект трюк).

## 2. Как войти в редактор

Никакой формы логина на виду нет. Чтобы попасть в редактор:

**3 раза кликнуть по кружку (●) в подвале сайта в течение 1 секунды.**

Появится окно, куда нужно ввести:
- юзернейм владельца репозитория,
- название репозитория,
- ветку (обычно `main`),
- **GitHub token**.

### Как сделать токен
GitHub → фото профиля → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**:
- Repository access: **Only select repositories** → выбрать свой репозиторий.
- Permissions → **Contents: Read and write**.
- Сгенерировать, скопировать (показывается один раз).

Токен сохраняется только в `localStorage` этого браузера — в код на GitHub не попадает. Даёшь его тем, кому доверяешь роль редактора; у остальных пользователей его просто нет, и они видят обычный сайт.

Открыть редактор снова — тот же клик по логотипу (если токен уже сохранён, сразу откроется форма нового поста). Кнопка «Выйти из редактора» в редакторе удаляет токен из браузера.

## 3. Как устроены посты

Всё хранится в `posts.json`:

```json
[
  {
    "id": "000002",
    "title": "Название поста",
    "date": "2026-09-02T10:00:00.000Z",
    "content": "## Текст в markdown\n\nс картинками вида ![подпись](uploads/000002-1.png)"
  }
]
```

- `id` — 6 цифр, генерируется автоматически (максимальный существующий + 1).
- Картинки при вставке в редакторе сразу загружаются в папку `uploads/` и вставляются markdown-ссылкой **прямо в то место текста, где стоял курсор**.
- При публикации сайт сам обновляет `posts.json` через GitHub API — коммит прилетает от имени владельца токена.

## 4. Важно про безопасность (раз это не критично, но всё же)

- Токен даёт запись **только в этот один репозиторий** (если создан как fine-grained и ограничен).
- Не давай токен людям вне списка редакторов — с ним можно менять/удалять любые посты.
- Если токен утёк — зайди в GitHub → Settings → Developer settings и отзови (revoke) его, создай новый.
